# Still — project description

Saved at the user's request on October 22, 2026. These details reflect the user's description at that time; deployment and test counts may change.

Still is a personal home-screen dashboard for the user's Samsung OLED TV. It runs directly on the TV and is built with JavaScript, HTML, CSS, and Samsung Tizen.

Features:
- Favorite apps and remote-friendly navigation.
- Local weather and sunrise/sunset appearance changes.
- A daily moon phase illustration.
- Obsidian, a pure-black theme designed for OLED.
- Simple settings with clear switches and rounded highlights.

A central design lesson was designing for a remote instead of a mouse: focus states, spacing, and navigation matter much more when viewed from across the room.

At the time of this description, the latest version was running on the user's TV, with 61 automated tests passing.
